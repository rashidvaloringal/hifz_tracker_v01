QCF V1 page fonts

Madani QCF V1 uses one page font per page. The first online installation caches the font in IndexedDB; subsequent rendering uses the local cached font.

Data integrity: page 1, page 2, line numbers, Surah headers, Bismillah lines and word ranges come from the supplied page maps. The app does not move Baqarah into Fatiḥah, does not invent missing lines, and does not add artificial flex spacing.
